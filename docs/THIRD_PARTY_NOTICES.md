# Third-party components

ModemDiag's own source code is MIT-licensed; see [LICENSE](../LICENSE).
The combined executable built with open-source PyQt6 is distributed under GPLv3 terms.
Qt and other bundled components retain their own copyright notices and licenses.

Each Windows or Linux binary ZIP includes its executable and one `NOTICES.txt` with consolidated
copyright/license texts and exact dependency-source URLs and SHA-256 hashes. A separate source ZIP
on the same release page contains matching ModemDiag source and build scripts, with build requirements
and dependency-source records for each platform. See the [source instructions](../README.md#license).
Full third-party notices are supplied with the binary downloads; this file is a guide to them.

## Command reference versions

Profiles identify documented model/firmware families; they are not a claim that every device was tested.
Definitions use functional command syntax and short application descriptions. References identify
technical sources and do not grant permission to copy entire manuals.
